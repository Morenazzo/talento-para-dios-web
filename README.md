# Talento para Dios — Padre Nuestro Challenge

Landing de campaña para financiar el **Concierto Talento para Dios** de septiembre 2026, donde bandas de distintos géneros presentan su versión del Padre Nuestro.

## Cómo verlo
Abre `index.html` en cualquier navegador. No requiere build ni dependencias (Tailwind y Font Awesome se cargan por CDN).

## Stack
- HTML estático
- TailwindCSS (CDN)
- Font Awesome 6
- JS vanilla (countdown, i18n ES/EN, modal de donación, share social)
